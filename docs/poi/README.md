# Слои POI из OpenStreetMap

Поверх любого базового слоя можно включить постоянную подсветку POI —
родников, кемпингов, магазинов и других объектов OpenStreetMap. Точки
загружаются для видимой области карты и остаются на ней, пока включена
категория.

## Включить категории

- Открой панель слоёв и нажми кнопку POI — откроется подменю с
  категориями, сгруппированными по темам.
- Отметь нужные категории: у каждой есть иконка, название и счётчик
  найденных точек. Чекбокс группы включает или выключает всю тему,
  поиск фильтрует список, а «Выбрать все» и «Снять все» переключают всё
  сразу.
- Выключение категории сразу убирает её точки с карты.

## Точки на карте

- Близкие POI объединяются в кластер: рисуется иконка категории, поверх
  которой стоит число точек. Приблизь карту — кластер раскроется в
  отдельные иконки.
- Клик по кластеру приближает карту к его границам. Если точки в
  кластере совпадают по координатам, откроется их список.
- Клик по точке открывает карточку: название, категория, теги и ссылка
  на объект в OpenStreetMap.
- Иконки — оригинальные из стиля OpenStreetMap и набора Maki, рисуются
  на белом кружке, их размер растёт с приближением. Число точек кластера
  стоит в правом верхнем углу иконки.

## Ограничения

- На мелком масштабе POI не загружаются: в панели появляется подсказка
  приблизить карту. У каждой категории свой минимальный зум.
- Слишком большая область тоже не загружается — приблизь карту.
- Если точек очень много, панель предупредит, что часть может не
  поместиться: приблизь карту, чтобы увидеть все.

## Сохранить выбор

Выбранные категории сохраняются в браузере и в ссылке (параметр `poi`),
поэтому ссылкой можно поделиться. Снять все категории — сбросить выбор.

## Настройка

- Ключ NextGIS можно вставить прямо в панели POI (поле внизу панели):
  подойдёт и сам ключ, и полная ссылка из кабинета NextGIS. Ключ
  сохранится в браузере и ускорит загрузку; после загрузки рядом со
  статусом видно, какой интерпретатор обслужил запрос. Ключ также может
  прийти из `config.json` рядом с сайтом или из `src/secrets.json` при
  сборке; приоритет — браузер, затем `config.json`, затем сборка. Ключ
  бесплатный, выдаётся в личном кабинете my.nextgis.com.
- Адрес Overpass API задаётся в `src/config.js` (`overpassApiUrl`), список
  запасных интерпретаторов — в `overpassApiFallbackUrls`. Без ключа
  используется зеркало VK Maps (`maps.mail.ru`): официальный
  `overpass-api.de` перегружен. Вместо зеркала можно указать любой другой
  публичный или собственный интерпретатор.
- При сетевой ошибке клиент сразу переключается на запасной интерпретатор,
  а при ответе 429/5xx или таймауте сначала повторяет запрос к тому же
  (медленный интерпретатор может ответить со второй попытки). Рабочий
  адрес сохраняется в браузере и пробуется первым при следующей загрузке.
- Удачные ответы кэшируются в браузере на 10 минут: повторный просмотр
  той же области после перезагрузки страницы не требует запроса.
- Каталог категорий — в `src/lib/leaflet.layer.poi/categories.js`:
  группа, названия RU/EN, фильтры по тегам OSM, иконка и минимальный
  зум. Новые категории можно добавлять без правки кода.
